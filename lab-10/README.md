จากการทดลอง ได้เรียนรู้ความหมายของ **Incident Wave** หรือคลื่นตกกระทบ ซึ่งเป็นคลื่นที่เคลื่อนที่เข้าหาขอบเขต และ **Reflected Wave** หรือคลื่นสะท้อน ซึ่งเป็นคลื่นที่เคลื่อนที่กลับหลังจากกระทบขอบเขต

#### 3.1 การคำนวณเลขคลื่น (Wave Number)

เลขคลื่นคำนวณได้จาก

```text
k = 2π / λ
```

แทนค่า `λ = 10.0 m`

```text
k = 2π / 10.0
  = 0.628 rad/m
```

ดังนั้น เลขคลื่นมีค่าเท่ากับ **0.628 rad/m**

#### 3.2 การคำนวณความถี่เชิงมุม (Angular Frequency)

ความถี่เชิงมุมคำนวณได้จาก

```text
ω = 2πf
```

แทนค่า `f = 1.0 Hz`

```text
ω = 2π(1.0)
  = 6.283 rad/s
```

ดังนั้น ความถี่เชิงมุมมีค่าเท่ากับ **6.283 rad/s**

#### 3.3 การคำนวณอัตราเร็วของคลื่น (Wave Speed)

อัตราเร็วของคลื่นคำนวณได้จาก

```text
v = fλ
```

แทนค่า `f = 1.0 Hz` และ `λ = 10.0 m`

```text
v = (1.0)(10.0)
  = 10.0 m/s
```

ดังนั้น อัตราเร็วของคลื่นมีค่าเท่ากับ **10.0 m/s**

#### 3.4 สมการของคลื่น

เพื่อให้สอดคล้องกับขอบเขตตรึงที่ `x = 0` กำหนดให���คลื่นตกกระทบเคลื่อนที่เข้าหาขอบเขตและคลื่นสะท้อนเคลื่อนที่ออกจากขอบเขต ดังนี้

สมการของคลื่นตกกระทบคือ

```text
yᵢ(x,t) = A sin(kx + ωt)
```

สมการของคลื่นสะท้อนจากขอบเขตตรึงที่ `x = 0` คือ

```text
yᵣ(x,t) = −A sin(kx − ωt)
```

เครื่องหมายลบในสมการของคลื่นสะท้อนแสดงถึงการกลับเฟส 180° เมื่อสะท้อนจากขอบเขตตรึง

ตามหลักการซ้อนทับ การกระจัดรวมของคลื่นคำนวณได้จาก

```text
y(x,t) = yᵢ(x,t) + yᵣ(x,t)
       = 2A cos(kx) sin(ωt)
```

สมการสุดท้ายเป็นสมการของคลื่นนิ่ง ซึ่งมีตำแหน่งโหนดและปฏิโหนดคงที่ในอวกาศ

### 4. อภิปรายผล

เมื่อคลื่นเคลื่อนที่ไปตามเส้นเชือกและเดินทางถึง **Fixed Boundary** คลื่นจะสะท้อนกลับโดยมีการกลับเฟส 180° ทำให้การกระจัดของเชือกที่ขอบเขตตรึงเป็นศูนย์เสมอ จึงเกิดโหนดที่ขอบเขตนั้น

```text
y = yᵢ + yᵣ
```

หากคลื่นทั้งสองซ้อนทับกันโดยมีเฟสใกล้เคียงกัน จะเกิด **Constructive Interference** ทำให้แอมพลิจูดรวมมีค่ามากขึ้น ส่วนการซ้อนทับกันที่มีเฟสต่างกัน 180° จะเกิด **Destructive Interference** ทำให้แอมพลิจูดลดลงหรือเป็นศูนย์

การซ้อนทับของคลื่นตกกระทบและคลื่นสะท้อนที่มีความถี่และแอมพลิจูดเท่ากัน แต่เคลื่อนที่ในทิศทางตรงข้ามกัน ทำให้เกิดคลื่นนิ่ง โดยโหนดเป็นตำแหน่งที่การกระจัดเป็นศูนย์ตลอดเวลา และปฏิโหนดเป็นตำแหน่งที่มีแอมพลิจูดสูงสุด

#### 4.1 ระยะห่างระหว่างโหนดที่อยู่ติดกัน

ระยะห่างระหว่างโหนดที่อยู่ติดกันเท่ากับ `λ/2`

```text
λ / 2 = 10.0 / 2 = 5.0 m
```

ดังนั้น ระยะห่างระหว่างโหนดที่อยู่ติดกันเท่ากับ **5.0 m**

#### 4.2 ระยะห่างระหว่างโหนดกับปฏิโหนด

ระยะห่างระหว่างโหนดกับปฏิโหนดที่อยู่ใกล้ที่สุดเท่ากับ `λ/4`

```text
λ / 4 = 10.0 / 4 = 2.5 m
```

ดังนั้น ระยะห่างระหว่างโหนดกับปฏิโหนดเท่ากับ **2.5 m**

#### 4.3 การคำนวณคาบ (Period)

คาบของคลื่นคำนวณได้จาก

```text
T = 1 / f
```

เมื่อ `f = 1.0 Hz`

```text
T = 1 / 1.0
  = 1.0 s
```

ดังนั้น คาบของคลื่นเท่ากับ **1.0 s** หมายความว่า คลื่นใช้เวลา 1.0 วินาทีในการสั่นครบหนึ่งรอบ

#### 4.4 ผลของการเปลี่ยนแปลงพารามิเตอร์

- เมื่อเพิ่ม **Amplitude** การกระจัดสูงสุดของคลื่นและแอมพลิจูดที่ปฏิโหนดจะเพิ่มขึ้น แต่ตำแหน่งโหนด ความถี่ และความยาวคลื่นจะไม่เปลี่ยน หากพารามิเตอร์อื่นคงที่

## Post-Lab Questions

### 1. What happens to the phase of a wave when it reflects from a fixed boundary?

เมื่อคลื่นสะท้อนจาก **Fixed Boundary** คลื่นจะกลับเฟสเป็นมุม 180° หรือมีเฟสเปลี่ยนไป `π` เรเดียน ดังนั้นคลื่นสะท้อนจึงมีเครื่องหมายตรงข้ามกับคลื่นตกกระทบที่ขอบเขต และเกิดโหนดที่ขอบเขตตรึง

### 2. How do constructive and destructive interference differ?

**Constructive Interference** เกิดจากคลื่นซ้อนทับกันโดยมีเฟสเดียวกันหรือมีผลต่างเฟสเป็นจำนวนเท่าของ `2π` ทำให้แอมพลิจูดรวมมากขึ้น ส่วน **Destructive Interference** เกิดเมื่อคลื่นมีเฟสต่างกัน `π` เรเดียน ทำให้แอมพลิจูดรวมลดลงหรือเป็นศูนย์

### 3. If the boundary were free (not fixed), how would the reflected wave change?

หากเป็น **Free Boundary** คลื่นจะสะท้อนกลับโดยไม่เกิดการกลับเฟส หรือมีการเปลี่ยนเฟสเป็น 0° ดังนั้นที่ขอบเขตอิสระจะเกิดปฏิโหนดแทนโหนด

### 4. How many nodes and antinodes would be present if L = 20 m and λ = 10 m?

เมื่อ `L = 20 m` และ `λ = 10 m` จะได้ `L = 2λ` และระยะห่างระหว่างโหนดเท่ากับ `λ/2 = 5 m` หากปลายทั้งสองเป็นขอบเขตตรึง จะมีโหนดที่ตำแหน่ง `x = 0, 5, 10, 15, 20 m` รวม **5 โหนด** และมีปฏิโหนดที่ตำแหน่ง `x = 2.5, 7.5, 12.5, 17.5 m` รวม **4 ปฏิโหนด**

### 5. How does interference explain resonance in musical instruments?

ในเครื่องดนตรี คลื่นที่สะท้อนกลับจะซ้อนทับกับคลื่นที่เกิดขึ้นใหม่ หากความถี่ของแหล่งกำเนิดตรงกับความถี่ธรรมชาติของเครื่องดนตรี คลื่นจะเสริมกันอย่างต่อเนื่อง เกิด **Resonance** ทำให้แอมพลิจูดเพิ่มขึ้นและเกิดเสียงที่ดังขึ้น ความถี่ที่ทำให้เกิดเรโซแนนซ์ต้องสอดคล้องกับเงื่อนไขของคลื่นนิ่งในเครื่องดนตรีนั้น
