### 1. วัตถุประสงค์และสิ่งที่ได้เรียนรู้

การทดลองนี้มีวัตถุประสงค์เพื่อศึกษาการสะท้อนและการแทรกสอดของคลื่นบนเส้นเชือก โดยใช้โปรแกรม VPython จำลองการเคลื่อนที่ของคลื่น ทำให้สามารถสังเกตพฤติกรรมของคลื่นและตรวจสอบความสัมพันธ์ระหว่างปริมาณทางฟิสิกส์ต่าง ๆ ได้อย่างชัดเจน

จากการทดลอง ได้เรียนรู้ความหมายของ **Incident Wave** หรือคลื่นตกกระทบ ซึ่งเป็นคลื่นที่เคลื่��นที่เข้าหาขอบเขต และ **Reflected Wave** หรือคลื่นสะท้อน ซึ่งเป็นคลื่นที่สะท้อนกลับเมื่อเดินทางถึงขอบเขต นอกจากนี้ยังได้ศึกษาหลักการ **Superposition** ซึ่งระบุว่า เมื่อคลื่นสองคลื่นเคลื่อนที่มาพบกัน การกระจัดรวม ณ ตำแหน่งใด ๆ จะเท่ากับผลบวกของการกระจัดจากคลื่นทั้งสอง

การทดลองนี้ช่วยให้เข้าใจหลักการสะท้อน การแทรกสอด และการเกิด **Standing Wave** หรือคลื่นนิ่ง รวมถึงความสัมพันธ์ระหว่างโหนด (**Node**) และปฏิโหนด (**Antinode**)

#### 3.1 การคำนวณเลขคลื่น (Wave Number)

เลขคลื่นคำนวณได้จาก

```text
k = 2π / λ
```

แทนค่า `λ = 10.0 m`

```text
k = 2π / 10.0
  = 0.628 rad/m
```

ดังนั้น เลขคลื่นมีค่าเท่ากับ **0.628 rad/m**

#### 3.2 การคำนวณความถี่เชิงมุม (Angular Frequency)

ความถี่เชิงมุมคำนวณได้จาก

```text
ω = 2πf
```

แทนค่า `f = 1.0 Hz`

```text
ω = 2π(1.0)
  = 6.283 rad/s
```

ดังนั้น ความถี่เชิงมุมมีค่าเท่ากับ **6.283 rad/s**

#### 3.3 การคำนวณอัตราเร็วของคลื่น (Wave Speed)

อัตราเร็วของคลื่นคำนวณได้จาก

```text
v = fλ
```

แทนค่า `f = 1.0 Hz` และ `λ = 10.0 m`

```text
v = (1.0)(10.0)
  = 10.0 m/s
```

ดังนั้น อัตราเร็วของคลื่นมีค่าเท่ากับ **10.0 m/s**

#### 3.4 สมการของคลื่น

สมการของคลื่นตกกระทบคือ

```text
yᵢ(x,t) = A sin(kx − ωt)
```

สมการของคลื่นสะท้อนจากขอบเขตตรึงคือ

```text
yᵣ(x,t) = −A sin(kx + ωt)
```

เครื่องหมายลบในสมการของคลื่นสะท้อนแสดงถึงการกลับเฟสของคลื่นเป็นมุม 180° เมื่อสะท้อนจาก **Fixed Boundary**

ตามหลักการซ้อนทับ การกระจัดรวมของคลื่นคำนวณได้จาก

```text
y(x,t) = yᵢ(x,t) + yᵣ(x,t)
```

เมื่อคลื่นตกกระทบและคลื่นสะท้อนเคลื่อนที่ผ่านบริเวณเดียวกัน จะเกิดการแทรกสอด และอาจก่อให้เกิดคลื่นนิ่ง

### 4. อภิปรายผล

เมื่อคลื่นเคลื่อนที่ไปตามเส้นเชือกและเดินทางถึง **Fixed Boundary** คลื่นจะสะท้อนกลับและเกิดการกลับเฟส 180° คลื่นตกกระทบและคลื่นสะท้อนจะเคลื่อนที่ผ่านบริเวณเดียวกันและเกิดการซ้อนทับกัน โดยการกระจัดรวมเป็นไปตามสมการ

```text
y = yᵢ + yᵣ
```

หากคลื่นทั้งสองซ้อนทับกันในเฟสเดียวกัน จะเกิด **Constructive Interference** ทำให้แอมพลิจูดของคลื่นรวมเพิ่มขึ้น ในทางกลับกัน หากคลื่นซ้อนทับกันในเฟสตรงข้าม จะเกิด **Destructive Interference** ทำให้แอมพลิจูดของคลื่นรวมลดลงหรืออาจเป็นศูนย์

การซ้อนทับของคลื่นตกกระทบและคลื่นสะท้อนที่มีความถี่และแอมพลิจูดเหมาะสมสามารถทำให้เกิด **Standing Wave** ซึ่งประกอบด้วยโหนดและปฏิโหนด โดยโหนดคือ ตำแหน่งที่การกระจัดของคลื่นเป็นศูนย์ ส่วนปฏิโหนดคือ ตำแหน่งที่การกระจัดมีค่าสูงสุด

#### 4.1 ระยะห่างระหว่างโหนดที่อยู่ติดกัน

ระยะห่างระหว่างโหนดที่อยู่ติดกันเท่ากับ `λ/2`

```text
λ / 2 = 10.0 / 2 = 5.0 m
```

ดังนั้น ระยะห่างระหว่างโหนดที่อยู่ติดกันเท่ากับ **5.0 m**

#### 4.2 ระยะห่างระหว่างโหนดกับปฏิโหนด

ระยะห่างระหว่างโหนดกับปฏิโหนดที่อยู่ใกล้ที่สุดเท่ากับ `λ/4`

```text
λ / 4 = 10.0 / 4 = 2.5 m
```

ดังนั้น ระยะห่างระหว่างโหนดกับปฏิโหนดเท่ากับ **2.5 m**

#### 4.3 การคำนวณคาบ (Period)

คาบของคลื่นคำนวณได้จาก

```text
T = 1 / f
```

เมื่อ `f = 1.0 Hz`

```text
T = 1 / 1.0
  = 1.0 s
```

ดังนั้น คาบของคลื่นเท่ากับ **1.0 s** หมา���ความว่า คลื่นใช้เวลา 1.0 วินาทีในการสั่นครบหนึ่งรอบ

#### 4.4 ผลของการเปลี่ยนแปลงพารามิเตอร์

- เมื่อเพิ่ม **Amplitude** การกระจัดสูงสุดของคลื่นจะเพิ่มขึ้น แต่ความถี่และความยาวคลื่นจะไม่เปลี่ยนแปลงโดยตรง
- เมื่อเปลี่ยน **Wavelength** ระยะห่างระหว่างโหนดและปฏิโหนดจะเปลี่ยนตาม เนื่องจากระยะดังกล่าวขึ้นอยู่กับ `λ`
- เมื่อเพิ่ม **Frequency** คลื่นจะสั่นเร็วขึ้น และหากความยาวคลื่นคงที่ อัตราเร็วของคลื่นจะเปลี่ยนตามสมการ `v = fλ`

ข้อจำกัดของการจำลองนี้คือ แบบจำลองถือว่าเส้นเชือกเป็นระบบอุดมคติ จึงไม่ได้คำนึงถึงแรงต้านอากาศ การสูญเสียพลังงาน และปัจจัยอื่น ๆ ที่อาจเกิดขึ้นในการทดลองจริง นอกจากนี้ ภาพหน้าจอเป็นเพียงภาพ ณ ช่วงเวลาหนึ่งของแอนิเมชัน จึงไม่สามารถแสดงพฤติกรรมของคลื่นตลอดช่วงเวลาได้ทั้งหมด

## Post-Lab Questions

### 1. What happens to the phase of a wave when it reflects from a fixed boundary?

เมื่อคลื่นสะท้อนจาก **Fixed Boundary** คลื่นจะกลับเฟสเป็นมุม 180° หรือมีเฟสเปลี่ยนไปครึ่งรอบ

### 2. How do constructive and destructive interference differ?

**Constructive Interference** เกิดจากคลื่นซ้อนทับกันในเฟสเดียวกัน ทำให้แอมพลิจูดของคลื่นรวมเพิ่มขึ้น ส่วน **Destructive Interference** เกิดจากคลื่นซ้อนทับกันในเฟสตรงข้าม ทำให้แอมพลิจูดของคลื่นรวมลดลงหรืออาจเป็นศูนย์

### 3. If the boundary were free (not fixed), how would the reflected wave change?

หากเป็น **Free Boundary** คลื่นจะสะท้อนกลับโดยไม่เกิดการกลับเฟส ดังนั้นคลื่นสะท้อนจะมีเฟสเดียวกับคลื่นตกกระทบที่ขอบเขต

### 4. How many nodes and antinodes would be present if L = 20 m and λ = 10 m?

เมื่อ `L = 20 m` และ `λ = 10 m` จะมีความยาวเท่ากับ `2λ` บนเส้นเชือก ดังนั้นตามรูปแบบการจำลองที่ใช้ จะมี **Node 5 จุด** และ **Antinode 4 จุด**

### 5. How does interference explain resonance in musical instruments?

ในเครื่องดนตรี คลื่นที่สะท้อนกลับจะซ้อนทับกับคลื่นที่เกิดขึ้นใหม่ เมื่อความถี่ของคลื่นตรงกับความถี่ธรรมชาติของเครื่องดนตรี จะเกิดการแทรกสอดแบบเสริมกันอย่างต่อเนื่อง ทำให้เกิดคลื่นนิ่งและแอมพลิจูดเพิ่มขึ้น ปรากฏการณ์นี้เรียกว่า **Resonance** และเป็นสาเหตุที่ทำให้เสียงมีความดังมากขึ้น
