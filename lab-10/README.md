### 1. วัตถุประสงค์และสิ่งที่ได้เรียนรู้

การทดลองนี้มีวัตถุประสงค์เพื่อศึกษาการสะท้อนและการแทรกสอดของคลื่นบนเส้นเชือก รวมทั้งศึกษาการเกิดคลื่นนิ่งจากการซ้อนทับกันของคลื่นตกกระทบและคลื่นสะท้อน

จากการทดลอง ได้เรียนรู้ความหมายของ **Incident Wave** หรือคลื่นตกกระทบ ซึ่งเป็นคลื่นที่เคลื่อนที่เข้าหาขอบเขต และ **Reflected Wave** หรือคลื่นสะท้อน ซึ่งเป็นคลื่นที่เคลื่อนที่กลับหลังจากกระทบขอบเขต นอกจากนี้ยังได้ศึกษาการกลับเฟสของคลื่นเมื่อสะท้อนจาก **Fixed Boundary** การแทรกสอดแบบเสริมและแบบหักล้าง ตลอดจนตำแหน่งของโหนดและปฏิโหนดในคลื่นนิ่ง

การทดลองนี้ช่วยให้เข้าใจความสัมพันธ์ระหว่างแอมพลิจูด ความถี่ ความยาวคลื่น และอัตราเร็วของคลื่น รวมถึงการประยุกต์ใช้หลักการซ้อนทับเพื่ออธิบายพฤติกรรมของคลื่น

#### 3.1 การคำนวณเลขคลื่น (Wave Number)

เลขคลื่นคำนวณได้จาก

```text
k = 2π / λ
```

แทนค่า `λ = 10.0 m`

```text
k = 2π / 10.0
  = 0.628 rad/m
```

ดังนั้น เลขคลื่นมีค่าเท่ากับ **0.628 rad/m**

#### 3.2 การคำนวณความถี่เชิงมุม (Angular Frequency)

ความถี่เชิงมุมคำนวณได้จาก

```text
ω = 2πf
```

แทนค่า `f = 1.0 Hz`

```text
ω = 2π(1.0)
  = 6.283 rad/s
```

ดังนั้น ความถี่เชิงมุมมีค่าเท่ากับ **6.283 rad/s**

#### 3.3 การคำนวณอัตราเร็วของคลื่น (Wave Speed)

อัตราเร็วของคลื่นคำนวณได้จาก

```text
v = fλ
```

แทนค่า `f = 1.0 Hz` และ `λ = 10.0 m`

```text
v = (1.0)(10.0)
  = 10.0 m/s
```

ดังนั้น อัตราเร็วของคลื่นมีค่าเท่ากับ **10.0 m/s**

#### 3.4 สมการของคลื่น

กำหนดให้ขอบเขตตรึงอยู่ที่ `x = 0` และให้คลื่นตกกระทบเคลื่อนที่เข้าหาขอบเขตในทิศทางแกน `x` ที่ลดลง สมการของคลื่นตกกระทบและคลื่นสะท้อนสามารถเขียนได้ดังนี้

สมการของคลื่นตกกระทบคือ

```text
yᵢ(x,t) = A sin(kx + ωt)
```

สำหรับขอบเขตตรึง คลื่นสะท้อนจะกลับเฟส 180° เมื่อพิจารณาที่ขอบเขต สมการของคลื่นสะท้อนที่สอดคล้องกับเงื่อนไข `y(0,t) = 0` คือ

```text
yᵣ(x,t) = A sin(kx − ωt)
```

ดังนั้น การกระจัดรวมจากหลักการซ้อนทับคือ

```text
y(x,t) = yᵢ(x,t) + yᵣ(x,t)
       = A sin(kx + ωt) + A sin(kx − ωt)
       = 2A sin(kx) cos(ωt)
```

สมการสุดท้ายเป็นสมการของคลื่นนิ่ง โดยมีโหนดที่ตำแหน่ง `sin(kx) = 0` และมีปฏิโหนดอยู่กึ่งกลางระหว่างโหนดที่อยู่ติดกัน ที่ตำแหน่ง `x = 0` จะได้ `y(0,t) = 0` สอดคล้องกับเงื่อนไขของขอบเขตตรึง

### 4. อภิปรายผล

เมื่อคลื่นเคลื่อนที่ไปตามเส้นเชือกและเดินทางถึง **Fixed Boundary** คลื่นจะสะท้อนกลับและมีการกลับเฟส 180° เงื่อนไขนี้ทำให้การกระจัดที่ขอบเขตตรึงเป็นศูนย์ตลอดเวลา

การกระจัดรวมของเส้นเชือกหาได้จากหลักการซ้อนทับดังนี้

```text
y = yᵢ + yᵣ
```

หากคลื่นทั้งสองซ้อนทับกันโดยมีเฟสสอดคล้องกัน จะเกิด **Constructive Interference** ทำให้แอมพลิจูดรวมมีค่ามากขึ้น และเกิดบริเวณปฏิโหนด ในทางตรงกันข้าม หากคลื่นมีเฟสต่างกัน 180° จะเกิด **Destructive Interference** ทำให้การกระจัดหักล้างกันและเกิดบริเวณโหนด

การซ้อนทับของคลื่นตกกระทบและคลื่นสะท้อนที่มีความถี่และแอมพลิจูดเท่ากัน ทำให้เกิดคลื่นนิ่ง ซึ่งมีตำแหน่งโหนดและปฏิโหนดคงที่ แม้ว่าจุดต่าง ๆ บนเส้นเชือกจะยังสั่นขึ้นลงตามเวลา

#### 4.1 ระยะห่างระหว่างโหนดที่อยู่ติดกัน

ระยะห่างระหว่างโหนดที่อยู่ติดกันเท่ากับ `λ/2`

```text
λ / 2 = 10.0 / 2 = 5.0 m
```

ดังนั้น ระยะห่างระหว่างโหนดที่อยู่ติดกันเท่ากับ **5.0 m**

#### 4.2 ระยะห่างระหว่างโหนดกับปฏิโหนด

ระยะห่างระหว่างโหนดกับปฏิโหนดที่อยู่ใกล้ที่สุดเท่ากับ `λ/4`

```text
λ / 4 = 10.0 / 4 = 2.5 m
```

ดังนั้น ระยะห่างระหว่างโหนดกับปฏิโหนดเท่ากับ **2.5 m**

#### 4.3 การคำนวณคาบ (Period)

คาบของคลื่นคำนวณได้จาก

```text
T = 1 / f
```

เมื่อ `f = 1.0 Hz`

```text
T = 1 / 1.0
  = 1.0 s
```

ดังนั้น คาบของคลื่นเท่ากับ **1.0 s** หมายความว่า จุดบนเส้นเชือกใช้เวลา 1.0 วินาทีในการสั่นครบหนึ่งรอบ

#### 4.4 ผลของการเปลี่ยนแปลงพารามิเตอร์

- เมื่อเพิ่ม **Amplitude** การกระจัดสูงสุดของคลื่นและแอมพลิจูดที่ปฏิโหนดจะเพิ่มขึ้น แต่ตำแหน่งของโหนดและปฏิโหนดไม่เปลี่ยนแปลง
- เมื่อเปลี่ยน **Wavelength** ระยะห่างระหว่างโหนดที่อยู่ติดกัน (`λ/2`) และระยะห่างระหว่างโหนดกับปฏิโหนด (`λ/4`) จะเปลี่ยนตามความยาวคลื่น
- เมื่อเพิ่ม **Frequency** คาบจะลดลง หากกำหนดให้ความยาวคลื่นคงที่ตามแบบจำลอง อัตราเร็วของคลื่นจะเพิ่มขึ้นตามสมการ `v = fλ`

ข้อจำกัดของการจำลองนี้คือ แบบจำลองถือว่าเส้นเชือกเป็นระบบอุดมคติ ไม่มีแรงต้านอากาศ การสูญเสียพลังงาน หรือการเปลี่ยนแปลงของความตึงตลอดเส้นเชือก ดังนั้นผลการจำลองอาจแตกต่างจากการทดลองจริงเล็กน้อย

## Post-Lab Questions

### 1. What happens to the phase of a wave when it reflects from a fixed boundary?

เมื่อคลื่นสะท้อนจาก **Fixed Boundary** คลื่นจะกลับเฟสเป็นมุม 180° หรือมีเฟสเปลี่ยนไป `π` เรเดียน การกลับเฟสนี้ทำให้การกระจัดที่ขอบเขตตรึงเป็นศูนย์

### 2. How do constructive and destructive interference differ?

**Constructive Interference** เกิดจากคลื่นซ้อนทับกันโดยมีเฟสเดียวกันหรือมีผลต่างเฟสเป็นศูนย์ ทำให้แอมพลิจูดรวมเพิ่มขึ้น ส่วน **Destructive Interference** เกิดจากคลื่นมีเฟสต่างกัน 180° ทำให้แอมพลิจูดหักล้างกัน และในกรณีที่มีขนาดเท่ากันพอดี การกระจัดรวมจะเป็นศูนย์

### 3. If the boundary were free (not fixed), how would the reflected wave change?

หากเป็น **Free Boundary** คลื่นจะสะท้อนกลับโดยไม่เกิดการกลับเฟส การกระจัดที่ปลายอิสระจึงมีค่าเป็นแอมพลิจูดสูงสุด และปลายอิสระจะเป็นตำแหน่งปฏิโหนดของคลื่นนิ่ง

### 4. How many nodes and antinodes would be present if L = 20 m and λ = 10 m?

เมื่อ `L = 20 m` และ `λ = 10 m` จะได้ `L = 2λ` ระยะห่างระหว่างโหนดเท่ากับ `λ/2 = 5 m` หากกำหนดให้ปลายทั้งสองเป็นขอบเขตตรึง จะมีโหนดที่ตำแหน่ง `x = 0, 5, 10, 15, 20 m` รวม **5 โหนด** และมีปฏิโหนดที่ตำแหน่ง `x = 2.5, 7.5, 12.5, 17.5 m` รวม **4 ปฏิโหนด**

### 5. How does interference explain resonance in musical instruments?

ในเครื่องดนตรี คลื่นที่สะท้อนกลับจะซ้อนทับกับคลื่นที่เกิดขึ้นใหม่ หากความถี่ของแหล่งกำเนิดตรงกับความถี่ธรรมชาติของเครื่องดนตรี คลื่นจะเสริมกันอย่างต่อเนื่อง เกิดเป็นคลื่นนิ่งและทำให้แอมพลิจูดเพิ่มขึ้น ปรากฏการณ์นี้เรียกว่า **Resonance** หรือการสั่นพ้อง ซึ่งทำให้เกิดเสียงที่ดังและชัดเจนขึ้น
