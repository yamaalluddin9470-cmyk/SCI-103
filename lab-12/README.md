## 3. Results

### Part A: สนามแม่เหล็กของลวดตรง

สนามแม่เหล็กที่เกิดจากลวดตรงยาวคำนวณได้จากสมการ

**B = μ₀I / (2πr)**

โดยที่

- **B** คือ ความแรงของสนามแม่เหล็ก
- **μ₀** คือ ค่าคงที่ทางแม่เหล็ก
- **I** คือ กระแสไฟฟ้า
- **r** คือ ระยะห่างจากลวด

จากการจำลองพบว่าลูกศรสนามแม่เหล็กมีทิศทางวนรอบลวดตรงเป็นวงกลม ซึ่งสอดคล้องกับกฎมือขวา ถ้ากระแสไฟฟ้าเพิ่มขึ้น สนามแม่เหล็กจะมีความแรงเพิ่มขึ้น และถ้าระยะห่างจากลวดเพิ่มขึ้น สนามแม่เหล็กจะอ่อนลง

ในโค้ดมีการคำนวณค่า B แต่ยังไม่ได้ใช้กำหนดความยาวของลูกศร ดังนั้นลูกศรในภาพจึงใช้แสดงทิศทางของสนามแม่เหล็กเป็นหลัก

### Part B: สนามแม่เหล็กของ Magnetic Dipole

สนามแม่เหล็กของ magnetic dipole คำนวณได้จากสมการ

**B = (μ₀ / 4π) [3(m · r)r / r⁵ − m / r³]**

โดยที่ **m** คือ เวกเตอร์โมเมนต์แม่เหล็ก และ **r** คือ เวกเตอร์ตำแหน่งจากจุดกึ่งกลางของแม่เหล็กไปยังจุดที่พิจารณา

จากการจำลองพบว่าสนามแม่เหล็กมีรูปแบบคล้ายสนามของแท่งแม่เหล็ก และสนามบริเวณใกล้แม่เหล็กมีการเปลี่ยนแปลงมากกว่าบริเวณที่อยู่ไกลออกไป

## 4. Discussion

จากการจำลอง Part A พบว่าสนามแม่เหล็กรอบลวดตรงมีทิศทางเป็นวงกลมรอบลวด ซึ่งตรงกับกฎมือขวา ถ้าเปลี่ยนทิศทางของกระ��สไฟฟ้า ทิศทางของสนามแม่เหล็กก็จะเปลี่ยนเป็นทิศตรงกันข้าม

ความแรงของสนามแม่เหล็กรอบลวดตรงเป็นไปตามสมการ **B = μ₀I / (2πr)** ดังนั้นสนามแม่เหล็กจะเพิ่มขึ้นเมื่อกระแสไฟฟ้าเพิ่มขึ้น และจะลดลงเมื่อระยะห่างจากลวดเพิ่มขึ้น

สำหรับ magnetic dipole สนามแม่เหล็กมีลักษณะคล้ายสนามของแท่งแม่เหล็ก โดยสนามบริเวณใกล้แม่เหล็กมีการเปลี่ยนแปลงมากกว่าบริเวณที่อยู่ไกลออกไป

ข้อจำกัดของการทดลองคือ ใน Part A โปรแกรมคำนวณค่า B ไว้แล้ว แต่ยังไม่ได้ใช้ค่า B กำหนดความยาวของลูกศร ลูกศรจึงแสดงทิศทางของสนามแม่เหล็กเป็นหลัก ไม่ได้แสดงความแรงของสนามแม่เหล็กโดยตรงทั้งหมด

### คำตอบคำถามท้ายการทดลอง

1. **สนามแม่เหล็กของลวดตรงมีความแรงขึ้นอยู่กับระยะห่างอย่างไร**  
   เมื่ออยู่ใกล้ลวด สนามแม่เหล็กจะมีความแรงมากกว่า และเมื่ออยู่ห่างจากลวดมากขึ้น สนามแม่เหล็กจะอ่อนลง

2. **ถ้าเพิ่มโมเมนต์แม่เหล็กเป็นสองเท่า จะเกิดอะไรขึ้น**  
   สนามแม่เหล็กของ magnetic dipole จะมีความแรงเพิ่มขึ้นตามขนาดของโมเมนต์แม่เหล็ก

3. **สนามแม่เหล็กของ magnetic dipole แตกต่างจากสนามไฟฟ้าของ electric dipole อย่างไร**  
   ทั้งสองแบบมีเส้นสนามโค้งคล้ายกัน แต่สนามแม่เหล็กไม่มีขั้วเดี่ยวที่แยกออกมาได้ เส้นสนามแม่เหล็กจึงมีลักษณะเป็นเส้นปิด

4. **กฎมือขวาใช้หาทิศทางของสนามแม่เหล็กได้อย่างไร**  
   ให้นิ้วโป้งชี้ไปตามทิศทางของกระแสไฟฟ้า นิ้วที่เหลือจะโค้งไปตามทิศทางของสนามแม่เหล็กรอบลวด

5. **ถ้าหมุนโมเมนต์แม่เหล็กไปตามแกน x จะเกิดอะไรขึ้น**  
   ทิศทางและรูปแบบของสนามแม่เหล็กจะหมุนตามโมเมนต์แม่เหล็ก
